# Skills (public evaluation layer)

Coastal Alpine Tech maintains a fleet of **93 named, versioned skills**. They are customisable for any industry under the same HITL and Te Mana Raraunga contract.

This public repository shows **one working set** — the **platform / skill-contract set**:

- `aether-core`
- `aether-skill-authoring`
- `aether-skills-ci`
- `aether-hitl-protocol`
- `cat-architectural-standards`

Other folders may still exist as **name cards**. Full procedures, templates, and scored playbooks are not the public product. They load from the private CAT Agent Harness under a written agreement.

Humans still advise, decide, sign, file, send, and pay. A skill cannot raise that ceiling.
