# Coastal Alpine Tech — Sovereign Trust Layer (Web3)

**Internal / partner briefing · Claim tier: L1 Designed · 4 August 2026**  
Not a live product claim. Not an offer of tokens or financial products.

## One sentence

CAT treats Web3 (Sui, Walrus, and related tools) as an **optional trust and value layer** on top of sovereign edge AI — used for high-value audit anchors and, later, carefully scoped real-world asset pilots — never as a dependency for core farm, Hub, or edge operation.

## Problem we address

Primary-industry and community platforms need provable integrity without surrendering data residency or Māori data sovereignty. Public chains are useful for anchors, not for hosting operational or personal data.

## What we design for

| Capability | Intent |
|------------|--------|
| Local-first edge | Nodes and Hub run with chain off by default |
| Hash anchors | Immutable pointers to off-chain audit packs |
| Consent-aware design | Te Mana Raraunga controls before any externalisation |
| Optional RWA path | Future pilots for verified lots or uptime credits — testnet first |
| DAO-lite governance | Multi-sig + written constitution before on-chain voting |

## What we do not claim (today)

- Live mainnet token products or public liquidity
- MicrogreensDAO / AetherDAO as production systems
- On-chain storage of farm telemetry, health, or whenua-linked personal data
- Regulated financial product status without NZ counsel

## Stack (design target)

- Sui — smart contracts and minimal anchor objects
- Walrus — decentralised storage for large evidence packs
- DeepBook — possible later liquidity; not required for trust anchors

## Safe partnership / grant language

> CAT is designing a sovereign trust layer so high-value operational evidence can be hash-anchored for integrity while data remains local-first under Te Mana Raraunga principles. Chain features are optional and claim-tier controlled.

Avoid: live TVL, guaranteed yields, retail token sales, or implied iwi endorsement.
