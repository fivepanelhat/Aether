- L1 Sui substrate + edge signing
- L2 Trust objects (hashes, Walrus, consent anchors)
- L3 RWA + DeepBook settlement

## Red lines
- No Te Mana Raraunga or Privacy Act violations on-chain
- No regulated-product token language without NZ counsel
- No agent key/contract actions without HITL L2+
- Core edge/Hub must run chain-off
