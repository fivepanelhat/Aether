# Minimum Viable Set — Early Production Guidance

These six controls form the smallest coherent set that can reasonably claim Te Mana Raraunga technical alignment for an early production or pilot system.

| Order | Control | Why first |
|-------|---------|-----------|
| 1 | **X2** Runtime Sovereignty Gate | Stops silent exfiltration; fail-closed default |
| 2 | **X1** Consent check before personal/cultural access | Enforces purpose and authority at runtime |
| 3 | **R2 + Kt2** Local-first / NZ residency preference | Jurisdiction and control |
| 4 | **Kt1 + R3** Encryption + owner-influenced keys | Protects the taonga itself |
| 5 | **X4** HITL L2+ on sovereignty-affecting changes | Human authority remains supreme |
| 6 | **W1 + X3** Provenance + sovereignty metadata | Restores context and enables later controls |

Once these are reliable, layer the remaining Should and Must controls according to risk and data sensitivity.
