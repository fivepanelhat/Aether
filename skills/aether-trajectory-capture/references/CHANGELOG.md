# Changelog — aether-trajectory-capture

## [0.1.0] — 2026-07-26

### Added
- Initial design and implementation of the trajectory-to-skill capture pattern.
- Semi-automatic trigger after successful multi-step runs.
- Compact structured trajectory package format.
- Novelty / overlap check with preference for updating existing skills.
- Mandatory HITL approval before any skill is written.
- Quality gates to prevent skill sprawl.
- Clear separation of responsibilities with `aether-skill-authoring`.
- Source attribution via trajectory ID in skill changelogs.
