# Changelog — aether-skill-composition

## [0.1.0] — 2026-07-27

### Added
- Initial design and implementation of ordered shortlist composition.
- Structured shortlist format (task summary, ranked skills with reasons and roles, confidence, fallback).
- Size discipline: target 2–5 skills, hard ceiling ~7.
- Context-dependent HITL (auto on high-confidence low-stakes; required on medium/high-stakes).
- Clear hand-off to progressive disclosure and to aether-trajectory-capture.
- Quality rules to prefer existing skills and avoid near-duplicates.
