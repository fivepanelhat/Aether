# Aether UI/UX Platform

Provides structured review frameworks, visual communication standards, design decision records, accessibility auditing, and cross-repo design consistency for the Whānau Preterm Support Hub and Aether ecosystem.

## When to Load

- Designing or reviewing any Hub or Aether UI component, page, or flow
- Creating architectural diagrams or visual documentation
- Accessibility audits (WCAG 2.2 AA target)
- Establishing or updating design tokens and cross-repo consistency
- Design decision records for significant UX choices

## Core Principles

- Mobile-first and progressive enhancement
- Cultural safety and Te Tiriti alignment in visual language
- Clear hierarchy and low cognitive load for stressed whānau users
- Consistent tokens and components across Hub and related portals
- Accessibility is non-negotiable (keyboard, screen reader, contrast)

## Review Checklist (summary)

1. Does the flow match the intended user journey and risk profile?
2. Are medical and cultural disclaimers visible where required?
3. Is interactive content keyboard-accessible and labelled?
4. Do colours and type meet contrast requirements?
5. Is the design consistent with existing Hub patterns?
