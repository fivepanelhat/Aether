# Te Mana Raraunga — Core Principles

**Source**  
Te Mana Raraunga — Māori Data Sovereignty Network  
https://www.temanararaunga.maori.nz/

**Nature**  
Foundational Aotearoa principles for Māori data sovereignty. Data is treated as a taonga; control, access, and benefit must respect rangatiratanga.

---

## The Six Principles (Operational Summary)

| Principle | Short Meaning | CAT Technical / Governance Response |
|-----------|---------------|-------------------------------------|
| **Rangatiratanga** | Authority and control | Decision rights, owner/jointly-controlled keys, no silent transfer of control |
| **Whakapapa** | Relationships and context | Provenance metadata, lineage of data/models/decisions |
| **Manaakitanga** | Care and dignity | Cultural/ethical review for high-stakes outputs; stigma checks; required disclaimers |
| **Kotahitanga** | Collective benefit | Purpose binding, collective consent pathways, exit rights |
| **Kaitiakitanga** | Guardianship | Encryption, local-first, no silent exfiltration, meaningful deletion, sensitivity classification |
| **(Supporting)** | Context & continuity | Consent graph, runtime sovereignty gate, HITL L2+ on sovereignty-affecting changes |
