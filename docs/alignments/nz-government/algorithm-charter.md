# Algorithm Charter for Aotearoa New Zealand

**Source**  
Official government instrument (data.govt.nz lineage)  
https://data.govt.nz/assets/data-ethics/algorithm/Algorithm-Charter-2020_Final-English-1.pdf  
Also indexed on OECD.AI

**Nature**  
Voluntary public-sector commitment to improve transparency and accountability in the use of algorithms. Emphasises partnership, human oversight, and impact assessment.

---

## Core Commitments → CAT Mapping

| Charter Commitment | CAT Operational Response |
|--------------------|---------------------------|
| Transparency | Structured audit trails of prompts, tool calls, decisions, and human overrides |
| Partnership | Te Tiriti / mana whenua engagement pathways; cultural review readiness for high-impact uses |
| Human oversight | Non-negotiable HITL gates (L2+ for production, health, cultural, external actions) |
| Impact assessment | Risk tiering + formal assessment for High / Critical / novel uses |
| Focus on real-world effects | Preference for measurable outcomes (CPST, half-life, grounding) over benchmark theatre |
