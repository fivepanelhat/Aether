# Algorithm Charter for Aotearoa New Zealand

**Source**  
data.govt.nz (Stats NZ / government data system)  
https://data.govt.nz/use-data/data-ethics/government-algorithm-transparency-and-accountability/algorithmcharter/  

**PDF**  
https://data.govt.nz/assets/data-ethics/algorithm/Algorithm-Charter-2020_Final-English-1.pdf  

**Nature**  
Non-binding commitment by government agencies to transparency, human oversight, and risk-aware use of algorithms. Useful spirit for any system that informs decisions about people.

---

## Commitments Relevant to CAT

| Charter theme | CAT response |
|---------------|--------------|
| Transparency | Explain how decisions are informed; structured audit trails |
| Partnership / people | Stakeholder consideration; cultural safety on Hub paths |
| Privacy / ethics | Privacy Act + Te Mana Raraunga controls |
| Human oversight | HITL L2+ on high-stakes and production actions |
| Impact assessment | Risk tiering before production features |
