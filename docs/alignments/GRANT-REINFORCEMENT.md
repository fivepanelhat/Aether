# Grant Reinforcement Links

**Purpose**  
Curated primary sources and 1–2 reinforcement links per theme for grant applications, pilot LOIs, and funder conversations.  
**Rule**  
Cite external sources for the claim; cite CAT controls for *how* we implement. Never present third-party benchmarks as CAT measured results. Respect scorecard tier (L1 = designed language only until L2 evidence).

**Status**  
Alignment Week — 27 July 2026  
**Owner**  
Coastal Alpine Tech

## How to use in a grant

| Column | Use |
|--------|-----|
| **Primary** | Footnote / bibliography — official instrument |

| **CAT bridge** | One sentence mapping to our control (HITL, local-first, MVS, CPST skill, etc.) |
